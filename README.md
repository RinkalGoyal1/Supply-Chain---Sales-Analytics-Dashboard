# 📦 Supply Chain & Sales Analytics Dashboard

## 🚀 Project Overview

This project is an interactive **Power BI dashboard** developed using the **DataCo Supply Chain Dataset** (180,000+ transaction records) and **470,000+ website access logs**. The dashboard transforms raw operational and customer interaction data into meaningful business insights using **Power Query**, **Data Modeling**, and **DAX**.

It provides a comprehensive view of sales performance, supply chain efficiency, customer behavior, product profitability, and website engagement, enabling stakeholders to make informed business decisions.

---

# 🎯 Project Objectives

* Monitor overall sales and supply chain performance.
* Track revenue, profit, and order trends.
* Analyze delivery performance and late delivery risk.
* Identify high-performing products and categories.
* Understand customer purchasing patterns.
* Monitor website traffic and product engagement.
* Provide an interactive dashboard for business decision-making.

# 🧹 Data Preparation

The following data preparation steps were performed:

* Imported multiple datasets into Power BI.
* Cleaned missing and inconsistent data using Power Query.
* Standardized data formats.
* Removed duplicates.
* Built relationships across multiple tables.
* Created a Star Schema data model.
* Developed calculated columns and DAX measures.
* Optimized the model for reporting performance.
